# Link U (ลิงค์ ยู) - แพลตฟอร์มงานและทักษะ มหาวิทยาลัยแม่โจ้

> **โครงงาน Application Link U**  
> สาขาวิชานวัตกรรมธุรกิจดิจิทัล คณะบริหารธุรกิจ มหาวิทยาลัยแม่โจ้  
> **ผู้จัดทำ:** น.ส.ชวัลรัชต์ วงษ์คำ, น.ส.ณิชาพร อำภา, นายต่อตระกูล ดวงสาร, น.ส.ทรรศน์มน ลอวิลาร  
> **อาจารย์ที่ปรึกษา:** อาจารย์พิชิต สิทธิกัน  

---

## 🌟 จุดเด่นและดีไซน์ (Design Aesthetics)
- **สไตล์ intern.th:** โทนสีน้ำเงินและขาว (Blue & White) สะอาดตา ทันสมัย เรียบหรู ใช้งานง่าย
- **โลโก้ทางการ:** ตราสัญลักษณ์มหาวิทยาลัยแม่โจ้ จากหน้าปกเล่มรายงานโครงงาน
- **Responsive:** รองรับทั้งจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
- **Micro-Animations:** เอฟเฟกต์ยกการ์ด เงาโปร่งแสง แถบเปอร์เซ็นต์แบบไดนามิก และแจ้งเตือน Toast

---

## 🛠️ โครงสร้างฐานข้อมูล Supabase (`schema.sql`)
1. **`profiles`**: ข้อมูลนักศึกษา และ อาจารย์/บุคลากร (บทบาท, คณะ, สาขา, ทักษะ, ความสนใจ)
2. **`jobs`**: ประกาศงาน/โครงการภายในมหาวิทยาลัย พร้อมค่าตอบแทนและเบี้ยเลี้ยงแยกกัน
3. **`applications`**: ใบสมัครพร้อมข้อความแนะนำตัว ไฟล์แนบใน Supabase Storage และคะแนน AI Matching
4. **`portfolios`**: แฟ้มสะสมผลงานและโปรเจกต์ของนักศึกษา (รูปภาพ, ลิงก์ Drive/GitHub/Figma)
5. **`messages`**: แชทเรียลไทม์ระหว่างนักศึกษากับอาจารย์ผู้ดูแลโครงการ รองรับข้อความ รูปภาพ ไฟล์ ลิงก์ และสถานะอ่านข้อความ
6. **`notifications`**: ประวัติแจ้งเตือนการสมัครงานใหม่สำหรับอาจารย์ พร้อม Realtime
7. **`reviews`**: คะแนนประเมิน (1-5 ดาว) และข้อเสนอแนะเมื่อเสร็จสิ้นโครงการ

## 🚀 ฟังก์ชันการใช้งานหลัก (9 Functional Requirements)

| ฟังก์ชัน | รายละเอียดและการทำงาน |
|---|---|
| **1) สมัครสมาชิก / เข้าสู่ระบบ** | แบ่งบทบาทอย่างเข้มงวด: **นักศึกษา** (หางาน, สะสมผลงาน) และ **อาจารย์/บุคลากร** (โพสต์งาน, ประเมินผล) |
| **2) โปรไฟล์และ Portfolio** | จัดการข้อมูลส่วนตัว ทักษะ เพิ่มผลงานรูปภาพและลิงก์ (คลิกที่ชื่อมุมขวาบนเพื่อเข้าหน้าโปรไฟล์ทันที) |
| **3) โพสต์/แก้ไข/ลบงาน** | เฉพาะอาจารย์/บุคลากร สามารถสร้าง แก้ไข ลบ และเปิด/ปิดรับสมัครงานได้ บันทึกเข้า Supabase ทันที |
| **4) ระบบ AI Matching** | คำนวณ % ความเหมาะสมเปรียบเทียบทักษะของนักศึกษากับคุณสมบัติงาน แสดงแถบเปอร์เซ็นต์และไฮไลต์ทักษะที่ตรงกัน |
| **5) สมัครงานและติดตามสถานะ** | นักศึกษากดสมัครงาน พร้อมระบบติดตามสถานะแบบ Pipeline 5 ขั้นตอนอย่างชัดเจน |
| **6) แชทภายในระบบ (Real-time)** | ส่งข้อความ รูปภาพ PNG/JPG/WEBP เอกสาร PDF/Word/Excel/PowerPoint/ZIP/TXT และลิงก์งาน พร้อม badge ข้อความยังไม่อ่าน |
| **7) แจ้งเตือนการสมัครงาน** | บันทึกแจ้งเตือนการสมัครใหม่ให้เจ้าของโครงการ และแจ้งเตือนทันทีผ่าน Supabase Realtime |
| **8) ระบบรีวิวและให้คะแนน** | เมื่อโครงการเสร็จสิ้น อาจารย์สามารถให้คะแนนดาว (1-5 ดาว) และความคิดเห็น ซึ่งจะแสดงในโปรไฟล์นักศึกษา |
| **9) Dashboard สถิติภาพรวม** | แสดงตัวเลขประกาศงาน ผู้สมัครทั้งหมด อัตราสำเร็จ และกราฟจัดอันดับทักษะที่เป็นที่ต้องการสูงสุด |

## ⚙️ วิธีการเชื่อมต่อ Supabase
1. เข้าไปที่ [Supabase Dashboard](https://supabase.com/dashboard)
2. ไปที่เมนู **SQL Editor** ทางด้านซ้าย
3. คัดลอกโค้ดจากไฟล์ `schema.sql` วางแล้วกด **RUN**
4. นำ **Project URL** และ **Anon Key** จากหน้า `Project Settings -> API` มากรอกในหน้าเว็บที่ปุ่ม **"⚙️ ตั้งค่า Supabase"** บนแถบเมนู
5. ระบบจะขึ้นสถานะ `🟢 Supabase เชื่อมต่อแล้ว` และจัดเก็บข้อมูลจริงลงใน Supabase ทันที!

การรัน `schema.sql` จะเพิ่มคอลัมน์ `student_year` ในตาราง `profiles` (พร้อมย้ายค่าชั้นปีเดิมจาก `year_level` ให้บัญชีนักศึกษาที่มีข้อมูล), ปรับตาราง `messages` ให้เก็บประเภทไฟล์และสถานะอ่าน, สร้างตาราง `notifications` และ trigger แจ้งเจ้าของโครงการเมื่อมีใบสมัครใหม่, สร้าง private bucket `application-attachments` และ public bucket `chat-attachments` สำหรับไฟล์ในแชท (PNG, JPG, WEBP, PDF, Word, Excel, PowerPoint, ZIP, TXT ขนาดไม่เกิน 10 MB)

> **คำเตือน:** ไฟล์ใน `chat-attachments` ใช้ public URL เพื่อเปิดดาวน์โหลดจากการ์ดในแชท ผู้ที่มี URL สามารถเข้าถึงไฟล์ได้ ห้ามใช้แนบข้อมูลลับหรือข้อมูลส่วนบุคคลที่ไม่ควรเผยแพร่

> **ก่อนใช้งานจริง:** ระบบยืนยันตัวตนปัจจุบันเป็นโหมดตัวอย่าง (รหัสผ่านเก็บในตารางโปรไฟล์ และ RLS อนุญาตการเข้าถึงแบบเปิด) จึงยังไม่เหมาะกับข้อมูลจริงหรือไฟล์ส่วนบุคคล ต้องย้ายไปใช้ Supabase Auth และกำหนด RLS/Storage policies ตามผู้ใช้ก่อนเผยแพร่

